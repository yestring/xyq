# 算法实现验收清单

本清单对应 `ALGORITHM_SPEC.md` 1.0.0，供后续编码阶段逐项执行。它是测试要求，**不表示交接时已经执行或通过模型测试**。发生冲突时以规格书为准，并先报告冲突。测试夹具可使用小型虚构数据；不得把夹具输出冒充训练结果。

等级说明：**P0 阻断**表示数据口径、时间隔离、算法语义或错误状态不符合规格时，停止相关阶段；**P1 必须**表示该阶段交付前须通过的功能和确定性检查；**P2 报告**表示完整实验必须提交的诊断记录。P2要求产出真实报告，不要求指标达到某个阈值。任何等级均不要求模型优于基线或得到显著性结果。

所有数值测试先比较未四舍五入值；整数分、ID、集合及日期边界精确比较，浮点结果使用明确且记录在测试中的容差。涉及不同预测期的小夹具只验证公式，不改变默认 H=7、L=28。
