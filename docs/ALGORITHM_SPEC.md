# 银行客户现金流预测与智能资产配置辅助决策系统 V1.0 算法实现规格书

文档版本 1.0.0　系统版本 V1.0　定稿日期 2026年11月15日

本规格约定正常日消费预测、年龄主导的三类客户聚类及固定投资比例映射的首版算法。编码 AI 应按模块逐步实现，每阶段提交可复现的输入、输出与检查结果。当前交接包只有规格、数据和示例，没有已实现的模型、系统代码或性能结果。

唯一规范正文为本文件。Word 文件是同内容阅读副本；配置 JSON、字段说明、验收清单和提示词均服从本文件。发现冲突时先报告，不自行混用旧文档。此前 V1.0 讨论稿、V1.1 评审稿和聊天中已被替代的设定均不作为编码依据。

本版固定业务需求：只预测日常消费的可观测代理；仅保留正常交易金额；单变量消费预测；年龄权重最大；三个客群与三对比例固定；普通客户与冷启动客户共用预测器。首版默认参数可以经独立验证调整，但不得更改上述业务范围。各簇是否符合完整财富画像、模型是否优于基线均须待实验，不能提前写成已实现的效果。

## 01 算法范围和输出

BankSim 是合成支付数据。系统名称保留“现金流预测”，当前算法实际目标为“已剔除已知欺诈的正常支付日总额预测”。它不预测收入、净现金流、余额或真实可投资金额。[1][2]

| 模块 | 输入 | 必须输出 |
| --- | --- | --- |
| 消费预测 | 客户可见日消费历史及合法检索参考 | 未来 H 天非负预测、总额、预测状态 |
| 客户分群 | 年龄段及可见消费统计 | 原始簇编号、业务客群、分群依据及状态 |
| 比例映射 | 业务客群 | 一对稳健投资和进取投资比例 |

| 业务客群 | 稳健投资比例 | 进取投资比例 |
| --- | --- | --- |
| 财富起步客户 | 0.80 | 0.20 |
| 财富增长客户 | 0.65 | 0.35 |
| 财富安享客户 | 0.85 | 0.15 |

每个客群只有一对比例；不存在“每类两套组合”或六套模板。稳健投资不是现金的同义词。本版不拆分现金、固收和权益，不加入预算、储备资金、收益率优化或适当性评估。比例由业务规则指定，不由 K-means 学习。

运行顺序为：验证原始数据 → 建立日面板及可见性 → 按实验划分拟合预处理与聚类 → 构建合法候选 → 训练共享预测器 → 输出预测、客群及比例 → 计算离线指标。

## 02 原始字段与数据校验

唯一交易输入是 data/raw/bs140513_032310.csv，594,643 行、10 列。读取 UTF-8 CSV；分类字段含字面单引号，例如 'C1093826151'。先去两端空白，再仅去一对外围单引号，保留内部字符。不得把客户和商户编号转为整数。

| 字段 | 规范类型 | 允许值或含义 | 用途 |
| --- | --- | --- | --- |
| step | int | 0 至 179，1步为1模拟日 | 时间索引 |
| customer | string | 非空客户ID | 实体标识 |
| age | string | 0至6或U | 年龄段 |
| gender | string | F、M、E、U | 个人或企业范围检查 |
| zipcodeOri | string | 本文件恒为28007 | 校验，不入模 |
| merchant | string | 非空商户ID | 追溯，不入模 |
| zipMerchant | string | 本文件恒为28007 | 校验，不入模 |
| category | string | 15种支付类别 | 诊断，不拆预测通道 |
| amount | decimal | 非负，最多2位小数 | 正常消费金额 |
| fraud | int | 0正常，1欺诈 | 离线清洗 |

age=0至6依次表示≤18、19—25、26—35、36—45、46—55、56—65、>65岁；U未知。gender 中 E 为企业，U为未知。age=0不能区分18岁和未成年人，不能当作成年资格证明。[2]

金额用十进制定点方式解析为 amount_cents 整数分后聚合；禁止浮点直接乘100后截断。多于2位小数、负值、非有限值、非法枚举、缺字段及空ID均产生阻断错误，禁止静默丢行。原始行号从1起计，不含表头，保存为 raw_row_id。

本文件无完全重复行；若后续输入出现重复，报告而不自动去重，因为没有独立交易ID，数值相同不必然表示同笔交易。年龄或类型在同客户内冲突也须阻断该客户的画像生成并报告。本版确认无此冲突。

## 03 清洗与客户可见性

先建立两个只读逻辑视图：raw_events 含全部合法记录；normal_events 仅含 fraud=0。raw_events只提供客户存在、属性来源及时间覆盖，欺诈金额不进入消费目标、行为特征或检索序列。欺诈标签是此离线实验的已知标签，不作为未来实时可知特征。

客户可见起点 a(i) 是 raw_events 中首条记录的 step，不是开户日。对于本完整文件，覆盖日为0至179；a(i)之后没有正常支付的日子是已观测正常消费0。a(i)之前是不可见，不能补成已观测0。最后一笔交易日不作为销户日。

```math
x(i,t) = sum(amount_cents(r) / 100), r满足customer=i、step=t、fraud=0
observed(i,t) = 1 当 a(i) <= t <= 179，否则为0
```

日面板保存全部4,112客户×180日，但 observed=0 的 target_cents 保存为 null。为描述性审计可临时将这些 null补0计算固定面板统计；训练和评价必须使用原掩码。

| 已核验统计 | 值 |
| --- | --- |
| 正常交易 | 587,443笔，4,112客户 |
| 欺诈交易 | 7,200笔 |
| 正常交易总额 | 1,870,843,256分，即18,708,432.56欧元 |
| 有效客户日 | 720,521个 |
| 有效客户日中零消费 | 151,903个 |
| 首次可见前单元 | 19,639个，必须遮罩 |
| 正常消费首日晚于raw首日 | 188客户，最大差值120天 |

原论文金额使用欧元，CSV无币种列；本版以“原数据金额单位”计算，页面可注明原论文欧元口径，不自行换算人民币。不得虚构真实年月日、星期、节假日或退休状态。

普通历史区间为[a(i),t]；截短历史区间为[t−Lc+1,t]，仅当a(i)≤t−Lc+1才进入“恰有Lc天”的实验。Tobs是允许区间内连续可见天数，包含零消费日，不是交易笔数或活跃天数。主数据没有中断标志；未来数据有缺失时，本版拒绝跨缺口拼接连续窗口。

## 05 画像特征与预处理

画像使用最近 n=min(W,Tobs) 个可见日，W默认28。特征顺序固定为 age_rank、log_mean、cv、positive_day_ratio。年龄rank为0至6的有序等级，表示等级距离而非精确岁数；U不编码成7。

```math
mu = sum(x) / n
sigma = sqrt(sum((x−mu)^2) / n)
log_mean = log(1+mu)
cv = sigma / max(mu,1)
p = count(x>0) / n
```

cv分母中的1是一个原金额单位的首版稳定常数；使用总体标准差ddof=0。mu=0时sigma=cv=0。输入计算保留浮点精度，展示时才四舍五入。真实零额交易不会增加正消费日计数。

| 特征 | 距离权重 | 预处理 |
| --- | --- | --- |
| age_rank | 0.60 | 不截尾，标准化 |
| log_mean | 0.20 | 按拟合样本1%与99%分位数截尾后标准化 |
| cv | 0.10 | 同上 |
| positive_day_ratio | 0.10 | 不截尾，标准化 |

仅用预热截止59日的聚类拟合队列计算分位数、均值和标准差；分位数使用线性插值。后续只transform，不refit。标准差为0的列在所有transform中固定输出0，并记录constant_feature，不能让测试值产生新尺度。

拟合队列条件：属于本实验训练ID；截至59已知F/M个人类型；已知年龄；至少28天连续可见历史。全零画像可参与拟合，cv按上式定义；不得为提高聚类效果静默删掉177名预热全零客户。ID切分前资格队列为3,979名；严格冷启动实验须与训练ID重新求交。

## 06 加权聚类与业务命名

```math
z(j) = (feature(j) − fitted_mean(j)) / fitted_std(j)
z_weighted(j) = sqrt(weight(j)) * z(j)
J = sum_i min_c sum_j weight(j) * (z(i,j)−center(c,j))^2
```

使用欧氏K-means，K=3，k-means++初始化，n_init=20，max_iter=300，tol=0.0001，random_state=42。年龄权重最大为已定要求；60/20/10/10是本版默认配置，不是已验证的最优值。sample_weight不代替特征权重。[4]

每个客户在拟合时只有一条画像，等权。中心保存在加权标准化坐标，同时保存原始队列各簇的年龄rank均值、年龄段分布和消费分布。按各簇原始年龄rank均值升序映射：A财富起步、B财富增长、C财富安享。相同均值依次按平均日消费、原始簇编号升序打破并列，确保可复现。

中心年龄差不足0.5个等级时置semantic_warning=true，阈值为本版解释提示规则，不是显著性检验。仍可按稳定排序展示名称，但必须说明“按年龄顺序映射，完整阶段画像尚未验证”。不能据此写收入最低、资产最高、未婚多数或已经退休。

有效拟合要求至少3个不同特征向量且最终有3个非空簇，否则返回CLUSTER_FIT_FAILED。每簇人数少于max(20,拟合人数的1%)时发出small_cluster警告，不人为移动客户填满簇。

新客户画像充分时按相同加权距离分配最近中心。画像低信息量指n<7或正消费日<2：若年龄已知且类型F/M，只按年龄维度到中心的距离暂定分群，并列时按映射后的A、B、C顺序选择，状态AGE_ONLY；检索时不强制同簇过滤。未知年龄或类型为U返回GROUP_UNKNOWN；企业E返回NON_PERSON。以上是输入状态，不是新增第四个簇。

## 07 普通客户与冷启动路由

本版默认C=14，L=28，H=7。Tobs≤14且>0走跨客户路径，Tobs>14走本人路径。训练中人工截短为1、3、7、14天，与该路由一致。

```math
ell = min(L,Tobs)
Q(i,t) = [x(i,t−ell+1), …, x(i,t)]
K(j,s) = [x(j,s−ell+1), …, x(j,s)]
V(j,s) = [x(j,s+1), …, x(j,s+H)]
```

候选最小字段为 donor_id、key_start、key_end=s、value_start=s+1、value_end=s+H、ell、H、donor_group、source_cutoff、library_version。K和V必须完整观测，不含目标客户隐藏历史。查询与候选K严格等长。

所有路径都满足value_end≤cutoff，其中训练cutoff=t，验证和测试主实验cutoff=119；本人路径另满足s+H≤t−ell，排除整条K+V与查询重叠。跨客户仅用训练供体，排除目标本人。

```math
本人候选步长为1时 N = max(0,Tobs−2*ell−H+1)
```

L=28、H=7时至少63天才可能有本人候选；62天无候选，63天1条。该式是连续历史及滚动库下的参考上界；本版采用候选步长7且主评价冻结库，应以实际过滤结果为准，不能直接把该式当候选数。

Tobs=0返回NO_HISTORY，不调用神经网络、不生成假预测。存在历史但本人候选数为0时不强制改走跨客户；使用同一共享模型的参考缺失状态。此举保持普通与冷启动路径的实验含义清晰。

## 08 候选库与相似检索

跨客户供体全集固定为本实验预热聚类拟合队列，簇标签直接取截至59日拟合的K-means labels并冻结；包括预热全零画像，不重新走目标客户AGE_ONLY分支。全库对照与同簇方法使用同一供体全集；全库只取消簇筛选。验证及测试客户不能相互成为供体。本人路径只需要本人合法历史，不要求本人属于跨客户供体队列。

候选键末日网格为 s=a(j)+ell−1+7k，k为非负整数；step_stride=7是减少重复计算的首版默认，后续可用1做敏感性实验。本人网格同理，起点取允许的连续历史起点。各ell=1至28按需建立网格，不只支持几种预设Lc。

```math
d(Q,K) = mean((log(1+Q)−log(1+K))^2)
w(r) = exp(−(d(r)−dmin)/tau) / sum_v exp(−(d(v)−dmin)/tau)
R = sum_r w(r)*V(r)
```

默认m=5、tau=1且必须>0。先过滤合法日期，再按距离、donor_id、key_end稳定升序；跨客户每供体最多2条，同供体选中的K+V区间互不重叠，采用按排序依次接受的贪心规则。本人路径不施加该供体上限，允许不同历史条目互相重叠，但都不能与当前查询重叠。

跨客户若正式同簇候选在每供体上限和区间非重叠约束后实际接受数少于m，改为对全供体库重新排序选取，不先锁定同簇结果；状态标记EXPANDED_ALL。AGE_ONLY、GROUP_UNKNOWN、NON_PERSON目标从一开始用全供体库并记录原因。全库仍不足则返回实际m′；m′=0返回参考全0及reference_available=0。权重只在真实返回的m′条上归一化，不能为凑数重复候选。

R在原金额尺度对V加权，再取log(1+R)作为网络输入。不能先平均log(V)再用expm1还原。距离权重不是置信概率。记录候选ID、距离、权重和扩库原因。分块计算精确距离，禁止分配所有查询×所有候选的全矩阵；按样本键缓存结果，训练轮次复用。

## 09 共享预测器与张量形状

本版唯一首选网络为双分支MLP，使用PyTorch实现，不同时开发LSTM、Transformer或多个模型平台。后续若更换结构作为独立实验保存。

设batch size为B。所有张量为float32。左补齐至L=28，保持右侧是最新日。真实0消费与补齐0的数值相同，但历史掩码不同。

| 张量 | 形状 | 定义 |
| --- | --- | --- |
| q_log | B×28 | 有效位置log(1+Q)，左侧补0 |
| q_mask | B×28 | 真实观测日为1，包括消费0；补齐为0 |
| r_log | B×7 | 有参考时log(1+R)，否则0 |
| r_mask | B×1 | 有参考1，无参考0 |
| y_scaled | B×7 | 标签正常日消费/a |

历史分支拼接q_log与q_mask，56维→Linear(56,64)→ReLU。参考分支拼接r_log与r_mask，8维→Linear(8,32)→ReLU。两分支拼接96维→Linear(96,64)→ReLU→Linear(64,7)→Softplus。所有线性层含bias。下式network指最后Linear层的logits；Softplus只施加一次。

```math
yhat_scaled = Softplus(network(q_log,q_mask,r_log,r_mask))
yhat_amount = a * yhat_scaled
loss = mean((yhat_scaled−y_scaled)^2)
```

a为本实验训练ID在step0至59的有效正日总消费的中位数，不是交易金额中位数；缺少正值则a=1。只在预热拟合并保存。输入采用log变换，输出采用线性金额尺度；不能对预测调用expm1。Softplus保证非负但通常不为精确0，不把小正预测自动截断以美化指标。

无参考时r_log和r_mask都为0，仍执行同一个模型；这就是线上回退。用于实验比较的“无检索模型”需独立训练同结构模型，永久关闭参考分支，不能与回退样本的结果混为一组。

## 10 模型训练与可复现规则

默认Adam，learning_rate=0.001，betas=(0.9,0.999)，eps=1e−8，weight_decay=0。batch_size=256，max_epochs=100。无调度器、无dropout、无梯度裁剪。若损失或梯度非有限，终止运行并记录，不静默跳过样本。

训练原点为59至112，先筛出具有完整历史与标签的样本。每轮抽样量为本实验普通模式有效(customer,t)对的数量，向上补齐完整batch。每次先均匀抽一个有效训练客户，再均匀抽该客户合法t；以0.5概率使用普通历史，否则在{1,3,7,14}中对当时可行的Lc均匀抽样。没有可行截短长度则使用普通历史并记录计数。

截短必须同时改变Q、画像、属性读取和目标客户可见范围；重新路由并检索。不能只切神经网络输入。参考存在时，再以0.20概率把r_log、r_mask一起设0，模拟无参考回退；不修改标签。所有随机操作使用运行种子。

验证时不随机遮挡参考。普通模型按普通验证模式评估；严格冷启动模型分别评估Lc=1、3、7、14四档，每个Lc先在客户内平均t及预测日的平方误差，再对该档客户等权平均，最后对四档MSE等权平均，作为早停分数；各方法使用共同有效样本。任何一档没有合法验证样本则VALIDATION_EMPTY，不训练到结束后假装成功。

保存验证MSE最低的权重，改善阈值min_delta=0，连续10轮无严格改善则停止；同分保留较早轮。最终恢复best checkpoint再测试。至少保存配置、随机种子、库版本、拟合变换、聚类中心、映射、a、网络结构、训练曲线、源数据hash和切分ID。

运行42、43、44三个随机种子检查初始化和抽样稳定性；strict客户ID划分始终使用固定split_seed=42，不随模型种子改变。三个模型种子分别驱动MLP初始化、抽样和参考遮挡，聚类种子固定42；聚类稳定性另以42、43、44重拟合并单报。首版可先用42完成开发验收，完整实验再补三种子。CPU必须可运行，GPU为可选加速。冒烟运行可缩小样本，但必须标明smoke，不能作为全量实验效果。

## 11 时间划分与客户隔离

t表示最后可见日，标签从t+1开始。所有统计、候选及属性均须满足各自截止日。以下为H=7的固定协议。

| 阶段 | 时间范围 | 允许操作 |
| --- | --- | --- |
| 预热 | step0至59 | 拟合画像变换、聚类、金额尺度a |
| 模型训练 | t=59至112，标签60至119 | 学习预测器；检索V末日≤t |
| 验证 | t=119至142，标签120至149 | 早停及模型选择；主参考库截止119 |
| 测试 | t=149至172，标签150至179 | 冻结模型和全部规则；主参考库截止119 |

普通实验 O：训练ID为截至119日已出现且至少有一个合法训练窗口的客户；验证测试只评估这些相同ID的后续区间。训练期未见客户单列，不混入“普通已见客户”的成绩。每个较早t仍要检查a(i)≤t，不能用119日名单让客户提前出现。

严格冷启动实验 C：将全部清洗后客户ID按字符串升序排列，使用NumPy default_rng(42)打乱；前floor(0.7N)训练，接着floor(0.15N)验证，其余测试。本文件N=4,112，对应2,878、616、618名。保存实际名单；不把独立四舍五入导致的数量写成固定协议。每组再按时间准入，不把没有样本的ID假装已评价。

实验O与C各自重新拟合预处理、中心和预测器，不能复用全客户拟合产物。C的验证测试ID不参与模型、尺度、聚类或供体库拟合；它们可使用自身开放的短历史形成查询。

训练库按每个t过滤；验证测试主库冻结在119。滚动库为独立扩展，只允许训练供体截至t新增的已到达记录，不更新中心或网络；不能与主结果混报。改H时重新推导所有合法t和网络输出维度，不仅修改配置数字。

## 12 评价指标与实验矩阵

对每个客户先汇总其有效切点和H个预测日，再对客户等权。设e(i,t,h)=yhat−y，T(i)为该客户有效切点数。MSE以原金额单位平方计，MAE和RMSE以原金额单位计。

```math
MSE_customer(i) = sum_t,h e(i,t,h)^2 / (T(i)*H)
MSE = mean_i MSE_customer(i)；RMSE = sqrt(MSE)
MAE = mean_i [sum_t,h abs(e(i,t,h)) / (T(i)*H)]
TotalAE = mean_i [mean_t abs(sum_h yhat(i,t,h)−sum_h y(i,t,h))]
```

RMSE明确为客户等权MSE的平方根，不是各客户RMSE的平均。C实验每个Lc单报以上指标，再报告四档均值。早停用四档MSE的均值；不能把不同Lc样本直接拼接后让某档占更大权重。指标计算不提前四舍五入。零消费存在，MAPE不作为主指标。

| 基线或消融 | 必须保持相同的内容 | 目的 |
| --- | --- | --- |
| 零预测、最近值、可见Q均值、Q中位数 | 同客户、t、Lc、标签 | 检查复杂模型是否必要 |
| 纯检索R | 同一候选过滤；无R回退Q均值 | 区分检索与网络贡献 |
| 无检索MLP | 同结构、训练预算、切分 | 评价参考分支增益 |
| 普通本人检索 | O同一评价样本 | 检查本人历史价值 |
| C全库与C同簇检索 | 同供体全集、时间、排序和模型预算 | 检查客群筛选价值 |

报告客户数、样本数、有效检索率、扩库率和无参考回退率。所有失败、回退和未知群体保留状态，不静默删除；无法预测样本单报覆盖率并统一各方法可比较集合。

分层报告Lc、年龄段、客群、正消费日占比及低信息状态。滑动标签高度重叠，不能把窗口视为独立样本。额外用验证t={119,126,133,140}、测试t={149,156,163,170}做非重叠检查。三种子及客户级配对重采样只描述当前模拟场景，不能声称跨年度或真实银行泛化。

## 13 聚类解释与固定比例映射

每次拟合输出cluster_summary，包括人数、占比、原始年龄rank均值、各年龄段比例、日均消费中位数与均值、cv和活跃度分布、small_cluster和semantic_warning。另报告加权空间轮廓系数，以及相同队列在不同种子下的分组稳定性。指标只评价结构，不证明真实财富阶段。

目标业务画像是：起步阶段通常较年轻，增长阶段具有较强消费能力，安享阶段偏向财富保值。现有数据只能支持年龄和消费观察。不能先写“簇A收入资产最低且未婚多数”“簇B收入最高且已婚多数”“簇C资产最高且退休”。[2][5]

对用于聚类的变量直接做常规ANOVA并据此声称“差异显著证明有效”，会忽略分组本身来自同一批变量。首版报告描述性差异、规模、稳定性及同簇检索的预测增益，不设置必须得到p<0.05的验收条件。[6]

正式分群FULL或年龄暂定AGE_ONLY且已有合法group_map时，可输出该名称对应的固定比例；AGE_ONLY须同时标注“仅按年龄暂定”。GROUP_UNKNOWN、NON_PERSON、NO_HISTORY时，group和两比例为null，说明原因。CLUSTER_FIT_FAILED则阻断整个实验，预测也为空，修复拟合问题后才继续。空值状态不算第四类客户，也不以0/0假装有效比例。

比例结果字段为group_name、allocation_status、r_conservative、r_aggressive、rule_version。有效比例要求0≤r≤1且绝对和差≤1e−9。计算使用原始小数，展示为百分比。此模块仅规则校验，不进行收益训练、资产回测或预算计算。

## 15 演算示例与边界例子

本节及examples/toy_walkthrough.json均为虚构演算，不是BankSim抽样或模型训练结果。示例临时用H=2、L=2、stride=1展示流程，不改变首版生产默认。

在t=3预测客户T的第4、5日。可见raw包含：第0日正常10；第1日欺诈50；第2日正常10和20；第3日正常20。均在开放历史内，年龄码2、类型F。清洗后日消费为[10,0,30,20]，欺诈50不进入消费，但第1日仍是已观测日。Q=[30,20]。

画像窗口4天：mu=15，sigma=sqrt(125)约11.18034，cv约0.745356，p=0.75，log_mean=log(16)。由于n<7，分群走AGE_ONLY。假设已经拟合的三个中心原年龄rank为[2,3,6]，目标rank2暂定为财富起步；这组中心是示例给定，不是由四条记录训练出来。

同客群过滤因AGE_ONLY而放宽至全训练供体。两个历史供体的K均为[30,20]，对应V分别为[10,20]和[30,40]；各K结束于s=1，V位于2、3日，满足s+H=3≤t。距离都为0，权重各0.5，R=[20,30]。不能把供体4、5日作为V。

为了演示评价，假设外部测试桩给出的模型输出为[18,28]，未来实际正常消费为[20,30]。此处没有执行神经网络：MSE=4、RMSE=2、MAE=2、预测总额46、实际总额50、TotalAE=4。展示配置(0.80,0.20)，同时保留AGE_ONLY提示。

另检验三种情况：无候选时R=[0,0]且r_mask=0；开放窗口无raw记录时年龄与类型为U、分群未知而不是默认30岁；没有模型权重时不能使用上述测试桩数字响应真实预测请求。

## 16 可执行验收与开发顺序

本包的ACCEPTANCE_CHECKLIST.md逐项列出验收ID。验收只证明实现符合协议，不能要求未完成的模型必须取得某个效果。

阶段1只实现数据读取、校验、raw与normal双视图、日面板及质量报告。通过记录数、金额守恒、null/0语义、188名起点差异和原始hash检查后停止，不提前训练模型。

阶段2实现实验ID切分、时间样本、画像、变换、K-means、命名及比例映射。用合成小例子检查sqrt权重、未知年龄、AGE_ONLY和三对比例；保存队列和拟合截止日。

阶段3实现本人及跨客户候选、截止过滤、步长、距离、供体限制和回退。针对未来候选、目标本人、隐藏历史、空库、并列距离建立可检查的边界例子。检查冻结库与滚动库不混用。

阶段4实现简单基线、双分支MLP、训练、存取模型与预测接口。先跑smoke，再完成种子42的全量实验。未通过数据与时间边界检查不运行全量训练。

阶段5实现实验对照、分层评价、模型版本和命令行演示。确认算法输出接口后，另行制定软件界面、工程组织和软著材料方案，不在本阶段自行扩展。

每次让编码AI只做一个阶段；提供本规格、对应提示词和本地原始CSV路径。阶段末要求返回改动文件、执行命令、真实日志、通过项、失败项及下一步，不接受“看起来能运行”的口头说明。用户确认当前阶段结果后再授权下一阶段。

## 18 完整画像扩展与来源

若以后要实测“起步低收入低资产且多未婚、增长高收入且多已婚、安享资产最高”，需新增同客户、同截止日的可追溯数据。支出不能代替收入，消费低不能证明资产低，年龄高不能证明已退休。

| 新字段 | 最低要求 | 首次扩展用途 |
| --- | --- | --- |
| 收入 | 同币种、明确期间、区分经常及一次性收入 | 先作为簇的外部解释 |
| 资产总额及负债 | 估值时点、资产范围、净资产定义 | 检查资产积累画像 |
| 婚姻状态 | 生效日及未知状态 | 描述簇内比例 |
| 工作或退休状态 | 状态来源及生效日 | 验证退休阶段解释 |
